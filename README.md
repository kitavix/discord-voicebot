# 🤖 Discord Voice Bot

простой и легковесный бот для дискорда, который удерживает постоянное подключение (24/7) к заданному голосовому каналу и позволяет вручную воспроизводить аудиофайлы прямо из консоли хостинга.

---

## ⚡ Особенности

* **24/7 в голосовом канале:** автоматически переподключается при дисконнектах, падении сервера или кике бота из войса.
* **управление из консоли:** воспроизведение и остановка звуков текстовыми командами без использования чат-команд в дискорде.
* **поддержка форматов:** `.mp3`, `.wav`, `.ogg`.

---

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/4ernyash/discord-voicebot.git
cd discord-voicebot
```

### 2. Установка зависимостей
> убедитесь, что у вас установлен Python версии 3.10+ и FFmpeg.
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
создайте файл `.env` в корневой папке проекта и заполните данные:
```env
DISCORD_TOKEN=ваш_токен_бота
GUILD_ID=айди_сервера
CHANNEL_ID=айди_гч
STATUS_TEXT=статус_бота
BOT_STATUS=сетевой_статус_бота (выберите что-то из этого: online, idle, dnd, invisible)
```

### 4. Добавление аудиофайлов
создайте в корне проекта папку `sounds` и загрузите в неё нужные аудиозаписи:
```text
project/
├── sounds/
│   └── ваш_звук.wav
├── .env
├── main.py
└── requirements.txt
```

### 5. Запуск
```bash
python main.py
```

---

## 🎮 Консольные команды

после запуска бота вводите команды прямо в окно консоли:

* `list` — отображает список всех доступных аудиофайлов в папке `./sounds`.
* `stop` (или `s` / `стоп`) — немедленно останавливает текущий играющий звук.
* `имя_файла` — воспроизводит указанный файл (расширения `.mp3`, `.wav` и т.д. можно не писать, например: `troll` или `explode`).
